## About

I’m a software developer at **Juspay**, building reliable payment systems and merchant integrations. My work spans payment flows, authentication, risk integrations, reconciliation, and scalable backend services.

I also build privacy-focused desktop software, including **CernoviX**, an on-device financial-email workspace available in external TestFlight for macOS.

## Focus Areas

- Payments, merchant integrations, refunds, reconciliation, and multi-currency flows
- Distributed backend systems, APIs, authentication, and fraud-risk integrations
- Native macOS development with SwiftUI and cross-platform desktop development with Electron
- Building reliable, testable software with observability and production ownership
